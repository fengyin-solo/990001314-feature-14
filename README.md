# 社区便民留言板

基于 PHP 原生开发的社区便民留言板网站，支持居民求助、意见建议、失物招领等功能。

## 功能特性

- **首页展示**：滚动显示最新留言信息，统计各类留言数量
- **留言发布**：用户可提交留言，选择类型（求助/建议/失物招领），支持图片上传
- **排序筛选**：支持按时间/热度排序，按类型筛选
- **后台管理**：管理员可审核、通过、拒绝、删除留言
- **角色权限**：超级管理员 / 审核员 / 只读账号三级角色，服务端按权限点鉴权
- **会话管理**：查看各设备活跃会话、一键退出其他设备，被退出的入口立即失效
- **安全登录**：连续失败 5 次锁定 15 分钟；会话空闲 30 分钟或 12 小时绝对过期
- **异常提示**：被踢下线、会话过期、账号停用、权限变更均有明确提示并回到登录页
- **多标签页同步**：同浏览器多标签页通过轮询 + BroadcastChannel 保持状态一致
- **响应式布局**：适配手机和电脑端

## 技术栈

- **后端**：PHP 原生开发
- **数据库**：MySQL
- **前端**：HTML5 + CSS3 + JavaScript（原生）
- **特性**：响应式设计、图片上传、分页、搜索

## 安装部署

### 环境要求

- PHP >= 7.4
- MySQL >= 5.7
- Apache / Nginx

### 安装步骤

1. 将项目文件上传到 Web 服务器根目录

2. 访问安装脚本创建数据库：
   ```
   http://your-domain/install.php
   ```

3. 安装完成后删除 `install.php` 文件

4. 访问首页：
   ```
   http://your-domain/index.php
   ```

5. 访问后台：
   ```
   http://your-domain/admin/login.php
   ```

### 默认管理员账号

| 账号 | 密码 | 角色 | 权限 |
|------|------|------|------|
| `admin` | `admin123` | 超级管理员 | 全部功能，含管理员账号管理 |
| `auditor` | `auditor123` | 审核员 | 审核留言、删除留言、处理举报 |
| `viewer` | `viewer123` | 只读账号 | 仅查看，不能做任何改动 |

> 已有数据库升级请执行：`mysql -u root -p community_board < database/migration_add_sessions_rbac.sql`

## 使用说明

### 前台功能

1. **浏览留言**：首页展示所有已审核通过的留言
2. **筛选类型**：点击类型标签筛选特定类型的留言
3. **排序方式**：支持按时间或热度排序
4. **发布留言**：点击"发布留言"进入提交页面
5. **查看详情**：点击留言卡片查看完整内容

### 后台管理

1. 登录后台管理系统
2. 查看所有留言（支持状态、类型筛选和关键词搜索）
3. 审核留言（通过/拒绝）
4. 删除不当留言
5. 查看留言详情

### 会话与权限

1. **会话管理**：左侧“会话管理”可查看当前账号（超管可查看全部）的活跃设备，
   支持退出单个设备、一键退出其他设备；被退出的设备下次请求（最迟 15 秒内）立即回到登录页。
2. **多标签页**：一个标签页退出登录或被下线，其他标签页同步回到登录页；
   账号角色在其他设备被修改后，其余标签页会自动重新加载并按新权限处理。
3. **角色管理**：超管在“管理员账号”中新建账号、调整角色、停用/启用、重置密码、删除账号；
   角色变更或停用会让该账号所有会话立即失效，重新登录后才使用新权限，不沿用旧状态。
4. **登录保护**：同一账号 + IP 连续失败 5 次锁定 15 分钟；
   会话空闲 30 分钟或登录满 12 小时自动过期，均会提示并回到登录页。
5. **只读约束**：只读账号不显示任何操作按钮，直接调用写接口返回 403，越权访问页面进入 403 页。

## 注意事项

- 安装完成后务必删除 `install.php`
- 修改默认管理员密码
- 确保 `uploads/` 目录有写入权限
- 建议配置 HTTPS 保障数据传输安全
